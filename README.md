# Date Explorer

Chcę, żebyś stworzył aplikację, która będzie losować pośród 50 krajów na całym świecie (wybierz największe, najpopularniejsze i ciekawe kulturowo) jeden z nich, a następnie podawać tradycje, stereotypy, jedzenie, filmy i muzykę związane z tym krajem. Będzie to pomysł na randkę. Wylosowany kraj = dzień powiązany z tym.
